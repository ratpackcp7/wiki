# GPT-5.2

OpenAI's most advanced model series for professional knowledge work, released December 11, 2025. Positioned as a response to Google's Gemini 3 ("code red" declared Dec 1).

## What changed

Three-tier model line with significant performance jumps:

| Variant | API ID | Use case |
| :--- | :--- | :--- |
| **Instant** | `gpt-5.2-chat-latest` | Fast workhorse, 128k context, 16k max output |
| **Thinking** | `gpt-5.2` | Deep reasoning, coding, 400k context, 128k max output |
| **Pro** | `gpt-5.2-pro` | Highest intelligence, lowest error rates |

### Key benchmarks
- **ARC-AGI-2:** 52.9% (vs 17.6% for GPT-5.1 Thinking) — ~390x efficiency gain in one year
- **SWE-Bench Pro:** 55.6% coding benchmark
- **GDPval:** 70.9% professional work tasks (vs 38.8% GPT-5)
- **AIME 2025:** 100%
- **Vision:** error rates halved for chart reasoning and UI understanding
- **Factuality:** 30% fewer hallucinations vs GPT-5.1 Thinking

### Pricing (per 1M tokens)
- gpt-5.2: $1.75 input / $14 output
- gpt-5.2-pro: $21 input / $168 output
- 1.4x increase over GPT-5.1, but claimed better task efficiency

## New API features

### `/responses/compact` endpoint
Server-side compaction for long-running agent workflows. Performs loss-aware compression of conversation state, returning encrypted opaque items that reduce token footprint while preserving task-relevant information.

### Context window
400k tokens for Thinking/Pro, near-100% accuracy on 4-needle MRCR up to 256k.

## GPT-5.2-Codex (Dec 18, 2025)

Specialized variant optimized for agentic coding within the Codex ecosystem. Released Dec 18, 2025, one week after base GPT-5.2.

| Benchmark | Score |
| :--- | :--- |
| **Terminal-Bench 2.0** | 64% (vs 62.2% base GPT-5.2) |
| **SWE-Bench Pro** | SOTA (exact % not disclosed in announcement) |

Key improvements over base GPT-5.2:
- **Context compaction:** Native compaction for long-horizon tasks in large repos
- **Large-scale refactors:** Stronger on code migrations and multi-file changes
- **Windows environments:** Significantly improved reliability
- **Multimodal vision:** Better at screenshots, technical diagrams, UI mocks
- **Cybersecurity:** Major capability jump; "third jump" in security capabilities; Professional CTF gains; not yet "High" under Preparedness Framework

Real-world impact: Security researcher Andrew MacPherson used GPT-5.1-Codex-Max to discover CVE-2025-55183 (React Server Components source code exposure) via guided fuzzing workflow.

Availability: ChatGPT paid users immediately; API "coming weeks"; invite-only Trusted Access Pilot for vetted security professionals.
