# CP7 Mobile

Expo React Native mobile app for Chris Pack.

## Repository
- URL: https://github.com/ratpackcp7/cp7-mobile
- Platform: Android (arm64-only, no emulator on acerserver)

## Current Status (v1.3 goals)
- Markdown rendering in chat
- Session title editing (long-press rename)
- Typing indicator
- Reply/quote functionality
- Photo/file upload from chat

## Architecture
- Expo/React Native/TypeScript
- Unistyles 3.x theming (see expo-unistyles-theme-registration-fix skill)
- Hermes API backend at mcp.cp7.dev
