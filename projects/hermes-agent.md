# Hermes Agent

The agent that grows with you — core AI agent framework.

## Repository
- URL: https://github.com/ratpackcp7/hermes-agent

## Description
Hybrid AIAgent with CLI + API. Supports multiple LLM providers via OpenRouter, local memory via Honcho, and skill system.

## Key Features
- Multiple platform support (Telegram, Discord, API)
- Skill system for procedural memory
- Honcho integration for long-term memory
- MCP (Model Context Protocol) support
