# Anthropic Acquires Bun

Anthropic acquired the company behind Bun (JS runtime). Relationship started July 2024 when Anthropic adopted Bun for Claude Code.

## Key Points
- Bun: primary infra for Claude Code, Claude Agent SDK, future AI coding products
- Bun remains open-source, general-purpose JS runtime
- Claude Code hit $1B run-rate revenue in Nov 2025 (6 months after public launch)
- Anthropic revenue run rate: Jan $1B → Aug $5B → Oct $7B
- Jarred Sumner: Anthropic lets Bun skip VC monetization pressure
