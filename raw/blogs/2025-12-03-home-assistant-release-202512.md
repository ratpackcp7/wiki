# Home Assistant 2025.12: Triggering the holidays

## HA Labs
New space (Settings > System > Labs) for previewing features. Winter Mode first.

## Purpose-Specific Triggers & Conditions
- Intent-based: "When a light turns on" / "If the climate is heating"
- Target Areas or Labels directly
- New picker: Floor > Area > Device
- Labs preview feature

## Energy Dashboard
- Real-time power sensors (Watts)
- Downstream water meters
- Water Sankey Card
- Tabbed layout

## Dashboard
- System-wide default dashboard
- Manual Area/Floor reordering
- 75 levels undo/redo

## New Integrations
Airobot, Anglian Water, Backblaze B2, Google Air Quality & Weather, Philips Hue BLE, Victron BLE

## Breaking Changes
- HA Core, Supervised, 32-bit support fully removed
- go2rtc debug UI requires auth
- New template functions: clamp, wrap, remap
- Shelly reached Platinum quality scale
