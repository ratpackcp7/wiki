# FileBrowser Quantum Hits Stable

Evolution of filebrowser.org (now maintenance-only). Two tracks: Stable + Beta.

## Features
- OnlyOffice integration, 2FA, OIDC SSO
- Granular access control with OIDC groups
- Fast search via filesystem indexing
- Duplicate File Finder, Swagger API

## Platforms
Windows, Linux, macOS, FreeBSD, Docker.

## Limitations
- No command runners, no mobile apps, no WebDAV yet
- Indexing can use more memory (disableable per source)
