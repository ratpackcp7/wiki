# Our Best Customers Are Now Robots

Kurt Mackey on Fly.io's shift from Developer Experience (DX) to Robot Experience (RX). Growth driven by LLMs/AI agents doing "vibe coding."

Why robots choose Fly.io:
1. Fly Machines: ms startup, persistent, state management (create vs start/stop distinction)
2. Storage: Robots build via stateful trial-and-error, need persistent volumes + object storage
3. Networking: MCP needs long-lived connections, dynamic request routing critical

New features: MCP for Fly API, tokenized OAuth tokens for secure AI access.

Insight: "Robots don't run existing applications. They build new ones." Priority remains Managed Postgres for human developers.
