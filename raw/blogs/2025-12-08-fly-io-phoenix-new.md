# Phoenix.new – The Remote AI Runtime for Phoenix

Chris McCord's (Phoenix creator) online coding agent/IDE for Elixir/Phoenix running on ephemeral Fly.io VMs.

Features: Full root shell in Fly Machine, headless Chrome integration for UI verification, live development with instant deployment and preview URLs, database exploration via psql/Ecto, GitHub native (gh CLI pre-installed).

McCord: "Agents build software the way you did when you first got started... They want to pop a shell and get their fingernails dirty."

Can also build Rails, Expo React Native, etc. Predicts shift to CI-like agent environments.

Use cases: Issue triaging, rapid prototyping, legacy integration.
