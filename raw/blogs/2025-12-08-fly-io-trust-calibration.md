# Trust Calibration for AI Software Builders

Trust calibration = aligning user trust with actual capabilities. Over-trust → dangerous reliance. Under-trust → rejection of beneficial tools.

Cooperative vs Delegative systems need different calibration strategies. Three windows: Pre-interaction (onboarding), During-interaction (real-time cues), Post-interaction (feedback).

Performance vs Process information: Layered approach — high-level for novices, deep details for experts.

Adaptive calibration (monitoring user behavior) > static information.

Transparency paradox: Too much explanation causes overload. Anthropomorphism trap: Human-like language increases trust beyond capability. Use "tool-like" language instead.

Measuring: Acceptance rates, context metrics, pulse surveys.
