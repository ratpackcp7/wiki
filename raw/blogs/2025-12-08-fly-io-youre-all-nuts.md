# My AI Skeptic Friends Are All Nuts

Thomas Ptacek's argument that AI-assisted programming is the second most important development of his career. Skeptics dismissing LLMs as "fad" are using them wrong (copy-pasting from ChatGPT window). Modern AI = Agents: navigate codebases, use tools, ground truth via Unix tools/Git/linters.

Positive case: Eliminates "schlep" — tedious code that's majority of projects. Raises floor of mediocrity. Handle bookkeeping, dependency drama.

Rebuttal of common skeptic arguments:
- "You don't know what code is" → skills issue, treat like junior dev PR
- "Hallucinations" → solved in agentic workflows (compiler/linter catches, agent feeds back)
- "Bad at [Language X]" → varies by language (Go good, Rust harder but tooling challenge)
- "Not craft" → table analogy, don't hand-carve when you need a table

Ethics: Software community historically showed contempt for IP. Jobs displacement acknowledged — "we automate others' jobs away, ours are in line too."

Tools: Claude Sonnet, Cursor, Zed agent mode, Gemini 2.5 (50-70kloc context). "Kids today use asynchronous agents — 13 things for LLMs to work on, then check notifications for 13 PRs to review."
