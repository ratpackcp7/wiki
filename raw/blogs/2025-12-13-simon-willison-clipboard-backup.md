# Clipboard Backup

A utility to manage and preserve clipboard history locally.

- **Supported Formats:** Text, HTML, RTF, and images.
- **Storage:** Uses browser IndexedDB for persistent local storage (no server uploads).
- **Functionality:** Automatically creates backups upon pasting; allows for later restoration or downloading in original formats.

Available at: https://tools.simonwillison.net/clipboard-backup
