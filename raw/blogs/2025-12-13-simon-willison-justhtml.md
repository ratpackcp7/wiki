# JustHTML

JustHTML Playground - HTML5 Parser

An interactive browser-based tool for testing the JustHTML Python HTML5 parser via Pyodide.

- **Capabilities:** Parse, query, and manipulate HTML using CSS selectors.
- **Features:** Pretty-print documents, extract text, and convert HTML to Markdown.
- **Analysis Modes:** Includes tree structure visualization and streaming event inspection.
- **Privacy:** Runs entirely client-side.

Available at: https://tools.simonwillison.net/justhtml
