# JustHTML is a fascinating example of vibe engineering in action

JustHTML is a high-performance, pure Python HTML5 parser designed as a modern alternative to the inconsistently maintained `html5lib`.

**Key Technical Specifications:**
- Pure Python: No C extensions, making it compatible with environments like Pyodide.
- Compliance: Passes all 9,200+ tests in the official `html5lib-tests` suite used by browser vendors.
- Codebase: ~3,000 lines of implementation code supported by ~11,000 lines of tests.
- Features: Includes CSS selector queries and 100% test coverage.

## "Vibe Engineering" vs. "Vibe Coding"

Willison distinguishes between two types of AI-assisted development:
- Vibe Coding: Having an LLM generate code without review; suitable for prototypes but risky for production.
- Vibe Engineering: Expert programmers using coding agents responsibly to produce high-quality, reliable results. The human acts as a lead architect, making design decisions while the agent handles the "typing."

> "The agent did the typing; I did the thinking. That's probably the right division of labor." — Emil Stenström

## The Development Process (The "Agentic Loop")

Emil Stenström developed JustHTML over several months using VS Code with GitHub Copilot in Agent mode (utilizing Claude 3.7 Sonnet, Gemini 1.5 Pro, and Claude Opus).

### Sophisticated Engineering Steps Taken:
1. Test-Driven Foundation: Integrated the 9,200-test conformance suite from the start.
2. Architectural Control: Emil defined the core API (e.g., `TagHandler` base class) and instructed the model to implement it.
3. Iterative Refinement: Threw away the initial code to perform a rough port of Servo's Rust-based `html5ever` for better performance.
4. Performance Optimization: Built custom profilers and benchmarks to achieve micro-optimizations that beat existing pure Python libraries.
5. Hardening: Used a custom fuzzer to generate invalid HTML documents to ensure parser stability.
6. Code Hygiene: Used coverage reports to identify and prune unnecessary code generated by the agent.

## Actionable Insights for Developers
- Use Conformance Suites: When building standard-compliant tools (like HTML parsers), hook into industry-standard test suites early to guide the AI.
- Don't One-Shot: Complex libraries require months of "on-and-off" work and architectural pivots, not a single prompt.
- Automate Approval: In VS Code Agent mode, enabling automatic command approval (with a blacklist for sensitive commands) can significantly speed up the development loop.
