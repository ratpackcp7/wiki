# FastAPI 0.125.0

# FastAPI Release 0.125.0

**Release Date:** December 17, 2024
**Commit Hash:** `c75f17d`

---

## ⚠️ Breaking Changes
### End of Support for Python 3.8
FastAPI has officially dropped support for Python 3.8.

> **Note:** "This would actually not be a *breaking* change as no code would really break. Any Python 3.8 installer would just refuse to install the latest version of FastAPI and would only install 0.124.4. Only marking it as a 'breaking change' to make it visible."

---

## ♻️ Refactors & Modernization
*   **Syntax Upgrade:** Internal codebase syntax has been upgraded to **Python 3.9+**.
*   **CI/CD Cleanup:** Removed Python 3.8 from Continuous Integration (CI) pipelines.
*   **Documentation Update:** Removed Python 3.8 examples from the source documentation.

---

## 🌐 Documentation & Translations
*   **Sync/Updates:** Portuguese (pt), Spanish (es), and German (de) documentation synced and updated.
*   **New LLM Integration:** Added an LLM prompt file for French docs to facilitate automated translations.
*   **Removals:**
    *   Removed inactive translations for **Vietnamese** and **Persian**.
    *   Removed **Emoji** translations to simplify the new LLM autotranslation workflow.

---

## 🔧 Internal & Infrastructure Improvements
*   **Pydantic Flexibility:** Made Pydantic versions customizable within CI.
*   **Testing:** Configured coverage to error on main test failures.
*   **LLM Workflow:** Fixed `fetch-depth` for GitHub Actions, enabled monthly cron jobs for translation updates.
*   **Dependencies:** Bumped `markdown-include-variants` from `0.0.7` to `0.0.8`.
