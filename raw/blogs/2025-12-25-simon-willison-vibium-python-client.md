# Research: Vibium Python Client Investigation

Research [Vibium Python Client Investigation](https://github.com/simonw/research/tree/main/vibium-python-client#readme) — Examining the Vibium browser automation project, this investigation developed a Python client library that interoperates with Vibium's Go-powered "clicker" binary and existing Node.js tools. The Python client exposes both synchronous and asynchronous APIs, replicating advanced browser automation features such as auto-waiting, visibility checks, and custom commands (e.g., `vibium:find`, `vibium:click`) via WebDriver BiDi over WebSocket.
