# Codex Cloud Rebranded to Codex Web

**Source:** Simon Willison's Weblog
**Date:** December 31, 2025

### Overview
OpenAI has quietly rebranded the cloud-based version of its **Codex coding agent**. Previously known as **Codex cloud**, the product is now officially titled **Codex web**. This change was observed in documentation updates occurring between December 18 and December 31, 2025.

---

### Key Clarifications from OpenAI
Thibault Sottiaux, OpenAI's Codex engineering lead, provided context on the naming convention to align documentation with user terminology:

> "Just aligning the documentation with how folks refer to it. I personally differentiate between cloud tasks and codex web. With cloud tasks running on our hosted runtime (includes code review, github, slack, linear, ...) and codex web being the web app."

**Platform-Specific Naming:**
*   **Web Application:** Codex web
*   **iOS Application:** Codex iOS
*   **Backend/Automated Tasks:** Cloud tasks (hosted runtime for integrations like GitHub, Slack, and Linear)

---

### Industry Context & Comparisons
The rebranding highlights a divergence in naming strategies between major AI labs:

*   **Anthropic:** Uses the name **"Claude Code on the web"** (often shortened by users to "Claude Code for web"). Willison notes this is a "clumsy" name, especially since the tool is frequently accessed via a native mobile app.
*   **OpenAI:** Moving away from "Cloud" toward platform-specific suffixes (Web, iOS), despite the industry trend of using "Cloud" to denote hosted services.

---

### Evidence of Change
The transition was tracked via the Internet Archive:
*   **Dec 18, 2025:** Documentation still displayed the "Codex cloud" title.
*   **Dec 31, 2025:** Documentation updated to "Codex web."
