# FastAPI 0.128.1

**Release Date:** February 4, 2025
**Developer:** tiangolo
**Status:** 371 commits to master since this release.

---

### ✨ Features
*   **Mobile Optimization:** Added `viewport` meta tag to improve the Swagger UI experience on mobile devices ([#14777](https://github.com/fastapi/fastapi/pull/14777)).
*   **Improved UX:** Enhanced error messages for invalid query parameter type annotations ([#14479](https://github.com/fastapi/fastapi/pull/14479)).

### 🐛 Bug Fixes
*   **Schema Updates:** Updated `ValidationError` schema to include `input` and `ctx` fields ([#14791](https://github.com/fastapi/fastapi/pull/14791)).
*   **Python 3.14 Compatibility:** Fixed `TYPE_CHECKING` annotations to support PEP 649 ([#14789](https://github.com/fastapi/fastapi/pull/14789)).
*   **Security/Auth:** Credentials in the `Authorization` header now have leading/trailing whitespaces stripped ([#14786](https://github.com/fastapi/fastapi/pull/14786)).
*   **OpenAPI:** Fixed duplication of `anyOf` references for app-level responses when using `Union` models with specific content types ([#14463](https://github.com/fastapi/fastapi/pull/14463)).

### 📝 Documentation & Refactors
*   **Middleware Migration:** Updated docs to recommend `WSGIMiddleware` from `a2wsgi` instead of the deprecated `fastapi.middleware.wsgi.WSGIMiddleware`.
*   **Modern Syntax:** Updated embedded code examples to use **Python 3.10** syntax.
*   **Best Practices:** Encourages using return type annotations instead of `response_model` where possible.
*   **Contribution Policy:** Added instructions regarding the use of **LLM-generated code**, comments, and automated tools in Pull Requests ([#14706](https://github.com/fastapi/fastapi/pull/14706)).
*   **Refactor:** Re-exported `IncEx` type directly from Pydantic to avoid duplication.

### 🌐 Translations & LLM Integration
*   **LLM Prompt Updates:** Improved prompts for Ukrainian, Korean, Russian, Turkish, Portuguese, and French.
*   **New Prompts:** Added LLM prompt files for Traditional and Simplified Chinese.
*   **Model Adjustment:** Downgraded the LLM translation model to **GPT-5** (as noted in PR [#14823](https://github.com/fastapi/fastapi/pull/14823)) to reduce mistakes.
*   **Tooling:** Added a "Translation Fixer" tool and updated scripts to retry LLM responses if they fail validation.

### 🛠 Internal & Infrastructure
*   **Package Management:** Migrated to **`uv`** for dependency management ([#14676](https://github.com/fastapi/fastapi/pull/14676)).
*   **CI/CD:**
    *   Tests now run only on relevant code changes (skipping docs-only changes).
    *   Mypy is now run via `pre-commit`.
*   **Dependency Bumps:**
    *   `ruff`: 0.14.3 → 0.14.14
    *   `sqlmodel`: 0.0.27 → 0.0.31
    *   `typer`: 0.16.0 → 0.21.1
    *   `actions/cache`: v4 → v5
*   **Cleanup:** Removed specific test variants for Pydantic v1.
