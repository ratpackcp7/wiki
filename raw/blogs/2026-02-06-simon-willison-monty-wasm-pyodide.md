# Research: Monty WASM + Pyodide

**Source:** [Simon Willison's Weblog](https://simonwillison.net/2026/Feb/6/monty-wasm-pyodide/)  
**Date:** February 6, 2026

Research [Monty WASM + Pyodide](https://github.com/simonw/research/tree/main/monty-wasm-pyodide#readme) — Monty WASM + Pyodide explores compiling Monty—a Rust-based, sandboxed Python interpreter—into WebAssembly for seamless browser access. It provides two integration paths: a standalone WASM module accessible directly from JavaScript, and a Pyodide-compatible wheel for usage in Python-in-the-browser environments. The project enables safe, dependency-free Python code execution with features like variable injection, output capturing (including print statements), and robust error handling.
