# Research: rod-cli: Chrome Automation from the Command Line

Research [rod-cli: Chrome Automation from the Command Line](https://github.com/simonw/research/tree/main/go-rod-cli#readme)
 — Leveraging the rod browser automation library, rod-cli provides a lightweight Go-based command-line tool for scripting persistent headless Chrome sessions. Each CLI command connects to and manipulates the same long-running Chrome instance via DevTools Protocol, enabling seamless multi-step browser automation in shell scripts or interactive use.
