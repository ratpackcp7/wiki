# Research: Rod: Go Library for Chrome Automation — Comprehensive API Reference

Research [Rod: Go Library for Chrome Automation — Comprehensive API Reference](https://github.com/simonw/research/tree/main/rod-library-research#readme)
 — Rod is an advanced Go library designed to automate Chrome browsers using the Chrome DevTools Protocol, providing a comprehensive API for web scraping, browser control, element interaction, and robust waiting strategies. With high-level convenience methods (such as Must-prefixed methods for fast scripting) and direct protocol access, Rod enables streamlined workflows from simple scraping to complex automation scenarios, all without third-party drivers.
