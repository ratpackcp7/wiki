# Summary: Claude Code Pricing Confusion (April 2026)

On April 22, 2026, Anthropic sparked significant community backlash by briefly updating its pricing page to suggest that **Claude Code**, previously included in the $20/month Pro plan, would become exclusive to the **$100/month Max** and **$200/month Max 20x** plans.

## Key Events & Timeline
*   **The Change:** Anthropic silently updated `claude.com/pricing` to remove the Claude Code checkbox from the Pro tier.
*   **The Reaction:** Major discussions erupted on Reddit, Hacker News, and Twitter as users feared a "rug-pull" price increase.
*   **The Reversal:** Within hours, Anthropic reverted the pricing grid to show Claude Code back on the $20 Pro plan.
*   **The Explanation:** Amol Avasare (Anthropic’s Head of Growth) clarified via Twitter that this was a limited test.

## Official Statements
> "For clarity, we’re running a small test on ~2% of new prosumer signups. Existing Pro and Max subscribers aren’t affected." — **Amol Avasare, Anthropic**

Following the reversal, Avasare added:
> "was a mistake that the logged-out landing page and docs were updated for this test... we’ve reverted both the landing page and docs changes."

## Critical Analysis by Simon Willison
Willison highlights several reasons why this "test" was damaging to the brand:

*   **Trust & Transparency:** Using a tweet from an employee to explain a 5x price increase is insufficient. It creates uncertainty for developers building workflows around the tool.
*   **Accessibility:** A $100/month entry point makes the tool inaccessible for many users, particularly those in lower-salary countries or students/journalists.
*   **Strategic Blunder:** Claude Code currently defines the category of coding agents. Moving it to a high-cost tier hands a massive marketing advantage to competitors like OpenAI.
*   **The "Claude Cowork" Irony:** Willison notes that **Claude Cowork** remained on the $20 plan during the test, despite being essentially a rebranded version of Claude Code.

## Competitive Landscape: OpenAI's Response
OpenAI capitalized on the confusion immediately. **Thibault Sottiaux** (Codex engineering lead) stated:
> "Codex will continue to be available both in the FREE and PLUS ($20) plans. We have the compute and efficient models to support it... Transparency and trust are two principles we will not break."

## Key Takeaways
*   **Current Status:** Claude Code is officially back on the $20/month Pro plan for the general public, though a "2% test" may still be running for new signups.
*   **Long-term Impact:** The incident has shaken developer confidence. Willison suggests that if Codex remains free or affordable while Claude Code risks a price hike, educators and developers may switch to OpenAI's ecosystem for better long-term stability.
*   **Actionable Insight:** Users should monitor pricing pages closely; Anthropic appears to be aggressively "optimizing revenue growth" through A/B testing high-tier exclusivity.
