# Showboat v0.6.0

Released 16 Feb 2026 by simonw.

## Changes

- New Showboat Remote feature - set a `SHOWBOAT_REMOTE_URL` environment variable and any modifications to a Showboat document will also be POSTed to that URL, including image uploads. This enables remote monitoring of how Showboat is being used in a hosted agent environment. [datasette-showboat](https://github.com/simonw/datasette-showboat) is a new Datasette plugin that can accept, store and display these POST submissions. [#17](https://github.com/simonw/showboat/issues/17), [#18](https://github.com/simonw/showboat/pull/18)
