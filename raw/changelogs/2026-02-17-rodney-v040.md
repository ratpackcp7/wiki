# Rodney v0.4.0

Released 2026-02-17 by simonw. CLI tool for browser automation.

## New Commands
- `rodney assert` — runs JavaScript tests, exit code 1 on failure (CI/CD friendly)
- `rodney connect PORT` — debug already-running Chrome instance
- `reload --hard` — hard reload of current session
- `clear-cache` — clear browser cache

## Enhanced Functionality
- Directory-scoped sessions: `--local` and `--global` flags
- `rodney start --show` — visible browser window during automation
- `--insecure` flag for SSL/certificate errors
- `RODNEY_HOME` env var for custom state directories

## Technical
- Exit code 2 for errors (exit code 1 reserved for check/assertion failures)
- Windows support via build-tag helpers
- CI expanded to windows-latest and macos-latest
