# Release 0.129.1

Released 21 Feb 2025 by [@tiangolo](https://github.com/tiangolo). Commit [`c91fed9`](https://github.com/fastapi/fastapi/commit/c91fed9).

## Key Fixes

* **JSON Schema for Bytes:** Updated the schema to use `"contentMediaType": "application/octet-stream"` instead of the previous `"format": "binary"`. (PR [#14953](https://github.com/fastapi/fastapi/pull/14953))

## Documentation Updates

* **Security Enhancement:** Updated JWT documentation specifically to include measures for **preventing timing attacks**. (PR [#14908](https://github.com/fastapi/fastapi/pull/14908))
* **AI Integration:** Added the **Kapa.ai widget**, an AI-powered chatbot, to the documentation site. (PR [#14938](https://github.com/fastapi/fastapi/pull/14938))
* **Cleanup:** Removed Python 3.9 specific files that are no longer required following translation updates. (PR [#14931](https://github.com/fastapi/fastapi/pull/14931))

## Translation Improvements

Extensive updates to synchronize international documentation for: Korean (ko), Ukrainian (uk), Traditional Chinese (zh-hant), French (fr), German (de), Japanese (ja), Portuguese (pt), Spanish (es), Simplified Chinese (zh), Turkish (tr), and Russian (ru). Corrected typos in Russian (ru) translations.

## Internal & Infrastructure

* **Syntax Modernization:** Upgraded typing syntax to align with **Python 3.10** standards. (PR [#14932](https://github.com/fastapi/fastapi/pull/14932))
* **CI/CD Changes:** Modified test protocols to ensure tests always run on every push to the `master` branch and when triggered by the scheduler. (PR [#14940](https://github.com/fastapi/fastapi/pull/14940))
* **Dependency Bumps:**
  * `cryptography`: 46.0.4 → **46.0.5**
  * `pillow`: 12.1.0 → **12.1.1**
