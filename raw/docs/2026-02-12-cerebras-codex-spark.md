# OpenAI GPT-5.3-Codex-Spark Powered by Cerebras

Release Date: February 12, 2026

Cerebras and OpenAI have announced the research preview of GPT-5.3-Codex-Spark, the first model resulting from their collaboration. This model is specifically optimized for high-speed, real-time software development, leveraging the Cerebras Wafer-Scale Engine (WSE) to eliminate the latency typically associated with agentic AI.

## Key Performance Metrics
- Inference Speed: Over 1,000 tokens/second.
- Hardware: Cerebras Wafer-Scale Engine, featuring the industry's largest on-chip memory.
- Benchmark Performance: Outperforms GPT-5.1-Codex-mini on SWE-Bench Pro and Terminal-Bench 2.0 while completing tasks significantly faster.
- Scalability: Supports scaling to thousands of systems, providing multi-terabyte fast memory.

## Philosophy
While autonomous "agentic" coding allows machines to work for days without supervision, it often excludes human intuition. Codex-Spark bridges this gap for iterative development with real-time feedback loops.

Use Cases: Precise code edits, plan revisions, contextual codebase queries, UI/UX layout visualization, rapid styling refinement.

"Bringing wafer-scale compute into production gives us a new way to keep Codex responsive for latency-sensitive work." — Sachin Katti, Head of Industrial Compute at OpenAI

## Availability
- ChatGPT Pro Users: Codex app, CLI, VS Code extension.
- Developers: API access to select design partners.
- Future: Ultra-fast inference for largest frontier models later in 2026.
